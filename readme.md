Portofolio & Local Repository Hub

Dokumentasi profesional, portofolio interaktif, dan pusat repositori lokal yang dirancang untuk menampilkan profil karier sebagai **Business System Analyst**, **Marketplace Operations Specialist**, serta rekam jejak proyek pengembangan sistem informasi.

---

## 🚀 Tentang Proyek

Proyek ini dibangun menggunakan template web modern berbasis **Bootstrap 5**, yang dioptimalkan untuk lingkungan pengembangan lokal (seperti **Laragon** atau XAMPP). Halaman ini berfungsi ganda:
1. **Personal Branding & CV Digital:** Menyajikan profil ringkas, keahlian (*skills*), ringkasan pengalaman kerja, dan informasi kontak.
2. **Project Portfolio Hub:** Mendokumentasikan studi kasus nyata dari berbagai domain industri (FnB, IT Support, Manufaktur, hingga Property) lengkap dengan spesifikasi sistem dan tautan akses dokumen terkait.

---

## 🛠️ Tech Stack & Dependencies

Proyek ini menggunakan beberapa framework dan pustaka pihak ketiga untuk mendukung estetika dan fungsionalitas interaktif:

* **Framework CSS:** [Bootstrap v5.3](https://getbootstrap.com/)
* **Ikon:** [Bootstrap Icons](https://icons.getbootstrap.com/)
* **Animasi & Efek Transisi:** 
  * [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
  * [Typed.js](https://mattboldt.com/demos/typed-js/) (untuk efek teks dinamis pada bagian *Hero*)
* **Filter Layout Proyek:** [Isotope Layout](https://isotope.metafizzy.co/) (untuk filter kategori portofolio secara dinamis)
* **Slider/Carousel:** [SwiperJS](https://swiperjs.com/)
* **Lightbox Viewer:** [GLightbox](https://biati-digital.github.io/glightbox/)
